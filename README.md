# BitsGofer Studio's GameJam - 001

This is an async, at-your-own-pace jam, where we work on a game together.
We will try to work on a very small game, but going through the full development
cycle: from brainstorming, prototyping to production, polishing
and finallty: publishing.

The target group here is people who really want to get into gamedev, but don't
have a framework to get started (myself included).

As a result of starting from cluelessness, it will be a messy process.
But I fully intend to distill the experience here into some clearer insights,
to be used in developing more complex games in the future.

Going on this gamedev journey alone is pretty hard, so I hope the pressence
of others sharing the same path will create the needed synery to keep you going.
